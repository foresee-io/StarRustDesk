# StarRustDesk 1.2.21（1002021）修订版

## 本次新增与修复

1. 新增手机、平板独立键盘悬浮按钮，可拖动、一键打开或收起，不需要展开“控”。
2. 新增连续输入：软键盘开启后，点击远端其他输入框继续输入，不因点按远端画面而收起；保留全屏三指上滑，不因实体键盘和预设组合键自动弹出软键盘。
3. 优化应用单独投屏的实体鼠标接收：增加原生画面和上层窗口兜底，统一电视与本屏的坐标换算，并对多通路事件去重。
4. 修复鼠标兼容触摸事件提前松键后，点击补偿可能额外发送一次左键的问题；补充各输入层、目标显示设备、焦点和画面尺寸诊断。
5. 更新应用内最新更新说明、手势帮助及英语、繁体中文文字；同版本修订首次启动也会显示更新说明。

## 保留的 1.2.21 更新

- 手机、平板默认跟随系统旋转锁定；“控”中支持跟随系统、固定竖屏或横屏，仅对本次远控生效。
- 应用单独投屏使用独立方向策略，返回本屏后恢复原选择，不改变远端分辨率。
