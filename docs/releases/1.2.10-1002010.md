# StarRustDesk 1.2.10（1002010）

## 更新内容

1. 修复全屏按钮状态与文字不同步，增加切换防重复、失败恢复及离开页面时的系统栏恢复。
2. 全屏切换复用视频组件，按实际视频尺寸及显示目标判断重绑定，减少不必要的解码器重启和黑屏；真正旋转、换屏仍保留安全重绑定。
3. 优化手机和平板放大后的触摸鼠标画面跟随：中心附近随手势平移，停手即停，连续操作无需重新等待；虚拟鼠标同步支持。
4. 增加全屏切换与画面恢复的诊断阶段、耗时和错误码。
5. 诊断模式新增本地脱敏的系统崩溃、卡死及系统终止事件采集与导出；关闭诊断会取消订阅并清除应用归档，不自动上传。
6. 增强已保存设备在线查询阶段日志及网络类型关联，辅助排查家庭 Wi-Fi 场景下的异常。

更新弹窗与设置页更新日志同步使用以上内容，最新记录置顶；首次启动本版本显示更新说明。
