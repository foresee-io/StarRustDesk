# StarRustDesk 1.2.0（1002002）

## 新增与优化

- 新增官方 RustDesk Server Pro、第三方 rustdesk-api 账号登录入口，支持记住登录、退出及邮箱/TOTP 二次验证。
- 支持个人、共享及旧版地址簿读取，勾选设备导入本地；重复设备自动跳过，不覆盖已有名称、密码和分组。
- 新增可选的自建 ID 服务器账号连接认证，令牌绑定当前服务器与公钥；不进入连接备份或个人云同步。
- 新增与远端的文字聊天及未读提示，聊天记录仅保留本次连接。
- 优化平板横屏首页：上方快速连接、下方设备列表，详细编辑选项收纳到侧边面板。
- 横屏远控默认展开两侧快捷栏；软键盘弹出时保持画面比例并向上避让，不再整体缩小。
- 连接信息默认关闭，按需展开并支持拖动，优化位置限制与误触处理。
- 保存连接后显示自动向上淡出的“已保存”提示。
- 常用按钮统一圆角矩形风格，设置中可切换按钮样式。

应用首次启动更新弹窗与设置内更新日志同步更新，最新内容置顶。

## API 接入范围

本版支持账号密码登录及地址簿读取/导入，暂不含网页 SSO 和地址簿双向同步。
接口模拟测试和编译已覆盖相关流程；实际 Pro / 第三方部署尚需真实服务器联调验证。
