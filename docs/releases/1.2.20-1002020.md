# StarRustDesk 1.2.20（1002020）

## 更新内容

1. 新增简体中文、繁体中文和英语，默认跟随系统，可手动切换并保存偏好。界面文字与协议、按键、用户文件名和聊天内容分离，不因语言切换重建远控会话。
2. 优化折叠屏内外屏及横竖屏软键盘避让，保留当前缩放比例，按可见区域和最后鼠标位置共同上移画面与光标，折叠、展开、旋转后重新计算布局。
3. 新增实验性 HDR 接收和显示适配：识别 HDR10/PQ、HLG 及实际输出位深，连接信息新增动态范围和输出路径，区分原生 Surface、软件 HDR→SDR、系统适配和输出不支持。
4. AV1 软件解码增加 HDR→SDR；完善高位深 VP9/AV1 平面转换、解码器切换及会话重置后的色彩清理，增加脱敏色彩和显示设备诊断。

## 边界与待验收项

- HDR 为控制端接收/显示能力，不改变远端采集编码和协议协商。远端已转换为 SDR 的视频不能恢复为 HDR；H.265、10 位或 BT.2020 本身不代表 HDR。
- 真正 HDR 显示需远端发送真实 HDR 视频及本地显示器支持。系统解码在 SDR 屏上的转换、折叠屏内外屏键盘避让、多语言大字体布局仍需真机验证。
- Ubuntu 登录界面到桌面切换后黑屏/停帧问题目前仅完成分析，尚未在本版本修复；有线应用单独投屏实体鼠标的设备兼容性仍待实测。
- 包名：`com.yinhe.starrustdesk`；版本：`1.2.20（1002020）`。
- GitHub Release 仅提供未签名 HAP，正式签名 APP 留在本地用于 AppGallery 上架；未签名 HAP 需要自行签名后安装。
