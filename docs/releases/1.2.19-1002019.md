# StarRustDesk 1.2.19（1002019）

## 更新内容

1. 修复远端光标图层可能拦截实体鼠标点击的问题；完善鼠标、触控板与触摸兼容事件的识别、松键状态及点击去重，避免左右键被误拦截。
2. 修复输入 Windows 登录密码后，本地键盘已收起但放大画面的鼠标跟随仍被阻止的问题。按实际键盘可见性和编辑状态恢复跟随，保留缩放比例与画面位置，并防止过期焦点回调重新打开输入捕获。
3. 改善系统大字体下的按钮适配。常用按钮、键控快捷栏和底部导航随字体调整尺寸，已保存连接工具区支持换行，减少文字被截断。
4. 增加键盘可见性、输入焦点、缩放与画面跟随阻止原因的脱敏诊断。诊断默认关闭，不记录输入文字、密码或候选内容；更新后的首次启动弹窗和设置更新日志同步更新，最新内容置顶。
