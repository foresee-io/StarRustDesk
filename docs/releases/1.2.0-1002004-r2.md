# StarRustDesk 1.2.0（1002004）密码保护修订版

应用版本名和版本代码不变；使用新标签 `v1.2.0-1002004-r2`，保留此前 Release。

## 本次更新

- 已保存连接只显示“密码已保存”，不再将原密码填回输入框供小眼睛查看。
- 新输入的密码保留临时显示功能；保存成功后清空输入框，恢复已保存状态。
- 增加更换、取消更换、清除和撤销操作；清除密码需点击保存才生效。
- 只修改名称、分组等信息时保留原密码；更换远端 ID 后不再使用旧设备保存的密码。
- 保留已保存设备的直接连接、加密备份和恢复流程；本次不迁移凭据存储或修改认证协议。
- 应用更新弹窗与设置内更新日志同步加入说明。版本号不变，已读过 1002004 弹窗的用户不会重复弹出，可在设置中查看。

保留前一修订版的连接认证脱敏诊断，以及 1002004 的 PC 自适应连接布局、One-KVM 键鼠兼容等改动。服务器认证拒绝问题仍需用户复现并导出诊断日志后继续定位。
