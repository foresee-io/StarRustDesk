# StarRustDesk 1.2.0（1002004）

## 新增与优化

- 鸿蒙 PC 连接页采用顶部快捷连接、下方设备列表、右侧编辑面板；设备列表随窗口宽度显示双列/三列，窄窗口恢复单列。
- 新增按服务器及远端设备分别保存的键盘模式：自动、1:1 映射、传统。自动识别 One-KVM 后使用传统键盘路径，绕开扫描码解释不一致导致的串键。
- 新增真正的相对鼠标协议，支持触屏、虚拟鼠标和实体鼠标；切换模式先释放按住状态，重新进入画面、旋转和切屏时重置取样基点。
- 新增“自动 / 画面内嵌 / 独立光标”选项，避免 One-KVM 视频光标与客户端光标叠加，并保留普通 Windows 远端的真实光标反馈。
- 应用首次启动更新弹窗及设置内更新日志已同步。

## 使用说明

键鼠选项位于远控页面“控 → 手势 → 键鼠兼容”。识别到兼容 One-KVM 后默认使用传统键盘、相对鼠标及画面内嵌光标，支持手动覆盖。

相对鼠标目前面向声明 Windows 平台及 RustDesk 1.4.5 以上协议的兼容远端；PC 允许鼠标移出远端画面操作本地界面，暂不包含 Windows 客户端式锁定指针/无限回中。绝对坐标持续偏移、不同 One-KVM 固件和实际被控系统仍需实机验收。
