# StarRustDesk 1.2.13（1002013）

## 更新内容

1. 新增按设备设置断开后锁定远端、隐私屏幕及加密连接下的远端系统自动解锁；是否生效取决于被控端支持与授权。系统密码仅保存在本机安全存储，不参与备份或云同步。

4. 已保存设备的在线状态查询默认关闭。关闭时不查询服务器，设备图标不显示状态圆点和图例；需要时可在设置中开启。
