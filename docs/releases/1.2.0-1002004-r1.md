# StarRustDesk 1.2.0（1002004）诊断修订版

应用版本名和版本代码不变；本次用独立标签 `v1.2.0-1002004-r1` 发布，保留原 Release。

## 本次改动

- 增强连接认证诊断，区分服务器返回的令牌缺失、无效、过期、要求登录、权限拒绝等已知原因。
- 记录账号连接认证上下文是否存在、服务器和公钥是否匹配、请求是否携带令牌。
- 标明默认服务器是否使用内置公钥，避免把界面的空 Key 配置误认为请求未携带公钥。
- 补齐远控、文件传输、中继请求的拒绝诊断，确保新增信息进入用户导出的日志。
- 不输出密码、令牌和可能回显敏感信息的服务器原文；未知文案仍隐藏。认证、服务器选择、加密与降级策略不变。
- 保留 1002004 的 PC 自适应连接布局、One-KVM 键盘兼容、相对鼠标与光标来源选项。

这不是已确认修复服务器拒绝连接的版本。请在设置中开启诊断日志、重试原连接并导出日志，以便继续定位。
