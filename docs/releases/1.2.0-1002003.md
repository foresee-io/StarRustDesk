# StarRustDesk 1.2.0（1002003）

- 新增“高清优先”和“自定义”画质：码率比例 10%～2000%，目标帧率 5～120 FPS，参数随已保存连接备份和同步。
- 画质入口：新建或编辑连接 → 更多选项 → 连接模式，保存后下次连接生效；百分比不代表固定 Mbps。
- 对齐官方公共中继限制：自定义码率超过 100% 回退至 50%，目标帧率最高 30 FPS；自建服务器或直连允许更高设置，保留原有默认模式。
- 后台保持低帧率，回到前台恢复所选画质；首次登录、画质重发及解码回退时保留自定义参数。
- 恢复聊天面板中的“发起语音”入口及通话状态提示，支持取消呼叫、静音和挂断。
- 麦克风仅在用户授权、远端接听后启动；进入后台或断开远控连接时结束通话。
- 保留文字聊天、账号地址簿及上一版本的界面优化。
- 更新首次启动弹窗与设置内更新日志，新内容置顶。

## 使用提示

- 高码率会增加带宽、流量和耗电，网络不足时可能增加延迟；目标帧率不代表实际保证帧率。
- 语音通话需要远端客户端支持；拒绝麦克风授权不影响普通远控和文字聊天。
- 此版本已完成回归测试、双架构编译及调试包安装启动检查，实际高码率效果和两端通话仍需实机验证。
