# StarRustDesk 1.2.18（1002018）

## 更新内容

1. 修复应用单独投屏时实体鼠标连续移动事件可能被误过滤的问题。原生与界面事件按类型、坐标及时间匹配去重，避免点击后吞掉后续移动，保留触控与鼠标点击路径。
2. 优化投屏窗口远端指针的显示与位置更新；切换显示设备时清理旧鼠标状态，继续遵守相对鼠标、内嵌光标等模式的显示约束。
3. 修复选中 Ctrl 后通过软键盘输入 Q 等字母时，远端可能额外识别出 Shift 的问题。新增独立字符快捷键通道，区分字符与功能键编码；保留明确选择的 Shift、普通文本及中文输入。
4. 增加投屏鼠标移动、过滤与指针状态的按需限频诊断，以及字符快捷键发送路径记录。应用首次启动更新弹窗和设置中的更新日志同步更新，最新内容置顶。
