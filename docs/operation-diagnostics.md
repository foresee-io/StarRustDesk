# 操作诊断日志

本轮补充日志，不改变版本号。诊断开关默认关闭；需要排查时先在设置中开启，再复现问题并导出日志。开启之前的过程无法补记。

## 新增覆盖

- 地址簿同步：读取、冲突预览、写入前检查、权限、远端/本地写入和最终校验，失败时记录已写入数量。
- 文件操作：上传准备、文件夹扫描、取回保存位置选择、远端操作请求、拒绝、取消、超时和完成。
- 文件传输：方向、项目数、字节数；进行中最多每 10 秒记录一次进度和速度；保存阶段区分压缩、打开源文件/目标、复制和大小校验。
- 录像：启动结果、停止原因、文件大小、导出选择/复制/校验及删除结果。
- 配置扫码：扫码开始、失效、解码、无效配置及准备完成，不记录二维码内容。
- 会话恢复：重试开始、连接恢复、状态变化导致的取消或停止。
- 语音：权限、请求结果、状态变化、采集启停和静音变化，不记录音频或聊天内容。

## 字段

结构化操作日志使用 `op_id` 关联同一操作，`action` 表示操作，`step` 表示当前阶段，`after` 表示前一阶段，`elapsed_ms` 表示累计耗时。一次操作只输出一次结束状态。文件选择准备与实际传输是独立操作，拥有各自的编号。

`reason` 为固定错误分类（如权限、状态变化、空间不足、超时、校验失败），不含原始异常文本。`code=0` 表示没有可安全提取的数值错误码，并不表示操作成功；是否成功以 `step` 为准。原生返回值使用 `result` 或 `native_status`。

录像停止的 `kind`：0 手动停止、1 离开远控页面、2 检测到原生录像结束。远端文件操作的 `kind` 仍使用该操作的协议枚举，不应与录像停止原因混用。

## 隐私与开销

新增结构化日志仅接收白名单字段中的有限数值和布尔值，不写入密码、验证码、令牌、文件名、路径、服务器地址、二维码或用户输入内容。文件保存失败不再直接写入原始异常消息。日志输出失败不会改变业务结果；关闭诊断后停止写入。现有原生轮转和容量限制保持不变。

## 验证边界

自动测试覆盖开关、关联编号、耗时、字段过滤、异常脱敏、结束去重、日志故障隔离，以及录像导出成功、取消、I/O 错误和大小校验失败。构建通过不等同于真实设备与各类远端的功能验收；文件选择器、后台恢复和录音仍需设备测试。
