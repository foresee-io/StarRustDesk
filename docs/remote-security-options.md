# 远端安全选项

在“编辑连接 → 更多选项 → 远端安全选项”中，按设备配置以下功能。三项均默认关闭。

- **断开连接后锁定远端**：在登录请求中发送 RustDesk 的 `lock_after_session_end` 选项。是否实际锁屏由被控端决定；客户端不会把“请求已发送”误记为“锁屏成功”。
- **隐私屏幕**：被控端需支持并允许隐私模式。会话建立并收到画面后请求开启；远控工具栏可手动开关，按钮只在被控端回执成功后显示已选中。多显示器环境请先切到屏 1。
- **自动解锁远端系统**：仅在同时开启“断开连接后锁定远端”、远端为桌面系统、且已验证端到端加密时，参照官方桌面客户端向远端登录界面发送系统密码。它与 RustDesk 连接密码不同；远端已经解锁时，密码可能被输入当前焦点窗口，因此仅应在可信设备上开启。

系统密码保存在本机 AssetStore，设备解锁时才可读取，不参与连接备份或云同步。修改远端 ID 会清除旧密码；服务器地址、转发地址或公钥变更时，原密码不会自动发送到新配置。未加密连接（包括用户批准的临时降级）不发送系统密码。

新增的诊断日志组件 `remote-security` 只记录选项状态、请求是否入队、端到端加密状态、被控端隐私回执代码和跳过原因，不记录密码或验证码内容，也不记录系统密码长度。日志中的 `lock_on_disconnect_requested` 不等同于被控端已锁屏；`privacy_result state=4` 才表示被控端确认隐私模式开启。

真机验收需要分别检查：支持隐私屏的单屏和多屏被控端、隐私权限被拒绝的提示、断开后被控端是否确实锁定、加密连接下的系统密码输入，以及未加密/更换服务器后系统密码被跳过。构建和单元测试不能代替这些远端状态验证。
