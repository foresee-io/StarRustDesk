# One-KVM 键鼠兼容

连接后从“控 → 手势”进入“键鼠兼容（仅当前设备）”。配置按服务器和远端 ID 分开保存。

- 键盘：自动 / 1:1 映射 / 传统。自动仅在远端用户名为 `one-kvm` 且显示器名包含 `KVM Display`（完整名称匹配）时使用传统路径，其他设备维持旧行为。
- One-KVM 的传统路径把 USB HID 转成字符/控制键，不把 Windows 扫描码当成字符发送。显式 1:1 保留扫描码语义，不伪装修复 One-KVM 接收端的 Map 解码缺陷。
- 相对鼠标：支持报告 Windows 平台、协议版本不低于 1.4.5 的远端；识别的 One-KVM 默认开启，其他设备默认关闭。真实发送 MOVE_RELATIVE=5，不加显示器原点，不使用本地预测坐标限幅。按键和滚轮保持独立。
- 相对模式隐藏本地系统光标。One-KVM 使用视频自带光标；普通 Windows 使用远端传回的独立光标数据，不凭本地位置预测。
- 光标来源：自动 / 画面内嵌 / 独立光标。自动识别 One-KVM，画面内嵌时禁止额外光标叠加，包括原来的内嵌光标兜底绘制。
- 鸿蒙 PC 此次采用可移出画面的相对操作，不实现 Windows 式系统指针锁定/无限回中。手机触控和虚拟鼠标可反复滑动。
- 模式切换释放已有按键/鼠标按钮；离开画面、前后台切换、旋转、切屏重置相对取样基点。

## 实机验收（尚需执行）

1. 记录 One-KVM 版本、实际被控系统、客户端设备和键盘布局。
2. 自动/传统下测试 A–Z、数字、Shift+数字/标点、Ctrl+C/V、左右 Shift/Ctrl、CapsLock，按下/抬起不能粘连。
3. 相对模式测试单指滑动、连续抬手再滑、虚拟鼠标、实体鼠标、左右中键、滚轮、拖拽；移动到远端边缘后仍可反向移动。
4. 出入画面、切屏、横竖屏、弹窗和断开连接后，本地光标恢复，不能跳位或遗留按住状态。
5. One-KVM 不出现双光标；普通 Windows 相对模式仍显示真实远端光标；手动光标来源覆盖能生效。
6. 重新连接确认设置保留；换服务器后相同 ID 不串配置。
7. 普通 Windows/Linux/macOS 使用自动模式回归键盘、中文输入法、快捷键和绝对鼠标。

绝对鼠标下的 HDMI 分辨率、被控系统多屏映射造成的持续偏移，仍需实机定位；本次相对模式可绕开绝对坐标映射，但不宣称修复 One-KVM 设备端所有坐标问题。
