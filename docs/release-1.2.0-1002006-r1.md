# StarRustDesk 1.2.0（1002006）控制端与诊断修订版

本次保持应用版本名和版本代码不变，以 `v1.2.0-1002006-r1` 发布修订包。

## 更新内容

1. 新增独立文件传输会话、批量和文件夹上传、远端新建文件夹/重命名/删除。
2. 新增地址簿手动双向同步预览、冲突处理和设备标签管理；本地连接密码、密钥不参与同步。
3. 支持服务器配置二维码扫描和展示；扫描后需确认保存。
4. 新增远端画面 WebM 录像、导出及删除。
5. 完善限次自动重连、Wayland 文本输入授权、已接通语音的后台任务处理和单独投屏方向策略。
6. 增强操作诊断：关联编号、阶段、耗时、错误分类、取消/超时，以及限频的传输速度和进度记录；默认关闭，不写入密码、令牌、文件名、路径或用户输入内容到新增结构化日志。
7. 更新应用内更新日志；安装本修订后首次启动显示修订说明。

## 使用边界

- 不包含鸿蒙被控端。
- 文件夹上传保留文件层级，但不保留空文件夹，不跟随符号链接。
- 录像仅有视频，无声音；编码/分辨率变化、磁盘错误或容量限制时可能结束。
- 地址簿同步为用户确认的手动操作，不是服务端事务；并发修改或部分失败后应重新预览。
- 后台语音与投屏受系统和设备能力限制；上架前需确认隐私政策覆盖相应麦克风使用场景。
- 自动测试和构建不等于设备验收；新增能力尚需在实际手机、平板、投屏接收端以及 Pro/第三方服务器上验证。
- 本修订不提升应用版本代码；应用市场若要求高于已上线的版本代码，需要另行递增后重新构建。
