# 连续输入与独立键盘按钮

- 手机和平板的远控页面增加独立、可拖动的键盘悬浮按钮，无需展开“控”。竖屏默认在右下方功能栏上方，横屏默认在底部中央；键盘弹出后按钮仍留在可用区域内。开启时为淡蓝色，按钮再次点击即收起。
- 软键盘只能由用户点击按钮或全屏三指上滑开启。点击远端画面不把焦点交给原生画面或输入捕获按钮；仍可移动鼠标、点按远端输入框、使用滚轮，继续输入文字。
- 若远端点按引起短暂失焦/键盘隐藏，只在有限时间内恢复已由用户开启的输入会话。不监测画面猜测输入框，不从实体按键启动软键盘，不在其他弹窗、断线或离开页面后恢复旧焦点。
- 点击键盘按钮、系统返回或输入法收起可结束输入；断线、离开页面和窗口形态变化清理输入及延迟回调。输入焦点恢复失败也会结束有限重试，避免反复弹出。
- 保留中文组字、快捷键和原有折叠屏避让：键盘弹出前记录画面大小，保持缩放与平移，不因连续点按清空输入缓冲或缩小桌面。
- 诊断仅包含连续输入状态、短暂焦点交接和恢复结果，不记录键盘文字、密码或剪贴板内容。

## 验证边界

回归测试执行生产代码中的焦点和计时方法，覆盖远端连续点按、输入法收起、恢复失败、弹窗、断线、页面销毁、外接键盘和悬浮按钮边界。编译通过不等同于不同真机和输入法上的连续输入效果已验收；需在手机/平板上测试中文组字、切换输入框、横竖屏及系统收起。
