# 放大后手势距离缩短修复

2026-09-22，保持版本 1.2.10（1002010）。

## 原因与范围

RemotePage 的触摸响应组件位于随画面缩放/平移的 Stack 内。原代码把 TouchObject.x/y（组件局部坐标）的差值用于视野平移、中心跟随、拖拽阈值和捏合距离。缩放会压缩这份差值，画面平移还会反馈到下一次局部坐标。旧测试直接注入固定局部坐标，没有模拟组件逆变换，因此遗漏了该问题。

## 修改

- 手势距离/阈值使用 windowX/windowY，缺失时由当前变换重建视口坐标。绝对点击/远端命中映射继续使用组件局部坐标，不改变物理鼠标输入路径。
- 中心跟随接收真实窗口位移；非跟随及相对鼠标路径仅进行一次缩放换算。虚拟鼠标已处在未缩放的外层，其位移不重复修正。
- 手动平移保留原有 1.5 倍增益、边界约束和按帧合并机制，不请求视频刷新。
- 捏合距离和双指滚动使用固定坐标；捏合锚点仍通过局部坐标映射，使用上一次双指中心作为缩放锚点，避免同时平移时重复计算。
- 拖拽判定、双击距离及三指手势阈值不再随着画面放大而变大。
- 删除捏合后统一屏蔽 90ms 的逻辑；继续依靠原有残余手指排空及等待新 Down 的状态保护，允许真正的新手势立即初始化。
- 诊断开始事件附带缩放倍率与距离坐标系，不记录手指位置或远端内容。

## 验证

新增 test-touch-window-coordinates.cjs：执行生产方法，并根据实时缩放/平移生成逆变换后的组件坐标和独立窗口坐标。覆盖 1.5/2/4/5 倍相同物理位移、停手不漂移、平移反向、18vp 拖拽阈值、直接点按映射、相对鼠标换算、连续捏合和二次放大、双指滚动、新 Down 与残余手指隔离、坐标回退。

现有中心跟随、虚拟鼠标、双指右键/滚动、键盘修饰键和视频平移合并回归也需保持通过。自动化模拟与编译不能代替真机手感验收；需在手机/平板连续放大两次后核对中心跟随、移动画面和虚拟鼠标外区域拖动。
