# StarRustDesk 1.2.0（1002006）

- 完善官方账号认证、网页登录、登录恢复及取消流程，增加脱敏诊断日志。
- 修复账号与地址簿弹窗按钮在请求结束后仍不可点击；优化设置入口可读性。
- 单指移动画面按显示帧合并更新，减少未变化光标的像素复制。
- 分离 VP9 软解码入队与渲染锁，减少输入与画面提交间的等待。
- 修正应用单层图标：1024×1024、方角、不透明，并保留打包校验。
- 包含此前未单独发布的 1002005 密码保护与认证诊断更新。

应用首次打开此版本的更新弹窗、设置中的更新日志均已更新，最新记录在顶部。

## 下载说明

GitHub Release 仅提供未签名 HAP，需使用自己的调试签名后安装。正式签名 AppGallery APP 保留在本地用于上架，不在 GitHub 分发。

## 验证边界

账号弹窗按钮的启用和关闭已在设备上验证；官方账号登录和原失败远端仍需用户使用自己的账号复测。拖动及软解码性能改善需在实际远控负载下验证，不承诺完全消除卡顿。
