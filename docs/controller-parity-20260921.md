# 控制端能力补齐（2026-09-21）

> 以下为功能实现阶段记录；后续正式构建、签名及修订发布信息见 [1002006-r1 发布说明](release-1.2.0-1002006-r1.md)。

本轮只做控制端；未添加鸿蒙设备被控、屏幕捕获服务或无人值守服务。保留已有单独投屏适配。版本仍为 1.2.0（1002006），未提交或发布。

## 功能与入口

1. 已保存连接 → 更多 → 文件传输（不打开画面）：使用独立 FILE_TRANSFER 会话，支持密码及二次验证，不启动视频解码或输入捕获。
2. 远端文件列表：新建文件夹、重命名、删除；删除有不可撤销提示，收到远端确认才提示成功，超时提示刷新核对。拒绝根目录及相对路径逃逸，过期操作回包不污染传输状态。
3. 发送文件：一次选择最多 100 个，顺序上传，共用一次目标目录确认；取消后不继续下一项。发送文件夹递归暂存并上传文件内容，含隐藏文件，拒绝符号链接和特殊文件，最多 10000 文件、32 层。准备过程可取消，不删除用户原文件。
4. 设置 → 服务器账号与地址簿：手动双向同步预览、冲突选择、服务器设备改名/标签/删除。同步仅包含 ID、名称、标签，不上传本地连接密码、密钥或 IP 直连项。同步范围是本地全部 ID 连接与选中的地址簿，执行前必须核对服务器归属。
5. 设置 → ID/中继服务器：扫描配置二维码、显示当前填写配置的二维码。兼容 `config=JSON` 及原有官方配置字符串；扫码只填表预览，确认保存后才生效。二维码包含服务器地址、公钥，不包含设备密码。
6. 远控工具栏 → 录像/录像列表；设置也有录像列表：录像为 VP9/VP8 WebM，开始时临时请求 VP9，结束恢复原画质协商。后台写盘，队列/磁盘异常会停止，不假报完整；停止或离开后可导出、删除。
7. 已经认证的远控会话遇到明确的网络传输中断：前台最多尝试恢复两次（1 秒、3 秒），绑定当前账号及网络配置；主动断开、密码/身份验证错误、不安全降级会话不自动重试。仅文件会话不套用远控恢复流程。
8. Wayland：软键盘和文本粘贴涉及远端剪贴板时先做本次会话授权提示，物理键盘不受该提示影响。
9. 语音：已接通且后台任务已就绪的通话可继续到后台；任务被系统暂停/撤销就停止麦克风。并未以静音、伪音频保活。SSO 保留已有官方网页登录流程，修正误导性的失败说明。

## 明确的边界

- 文件夹上传保留文件及其层级，暂不保留空文件夹，不处理符号链接；纯空文件夹明确提示不可上传，可以在远端新建。
- 录像仅含远端画面，不含音频；等待首个可用关键帧超时、切屏后分辨率/编码变化、写盘异常或约 4 GB 限制会停止。尚未生成有效画面的空录像不能导出。保存于应用私有目录，不在现有云备份白名单中；取消导出保留原录像。
- API 同步不是服务端事务。执行前后重新核对数据，发生并发修改或部分写入失败不更新同步基线，要求重新预览。旧版整体地址簿接口缺乏原子 CAS，不能完全消除第三方同时写入的窗口。当前不做无确认的自动删除同步。
- 后台通话能否持续由设备系统策略决定，不保证无限保活。上架前需同步更新华为隐私政策中的麦克风后台通话使用场景。
- 扫码与文件夹选择依赖设备提供的系统能力；失败可继续使用配置文本导入或单文件/批量上传。
- 本轮不应被描述为“所有协议已经与官方实机互通验收”；新增功能的编译、单元验证与真实服务器/设备验收是不同阶段。

## 已执行的验证

- Windows Rust 测试：52 项通过，包含文件操作路径/结果隔离、身份验证/网络/输入回归，以及实际 VP9 数据封装 WebM 后由 FFmpeg 解码。
- 脚本测试：32 组通过，包含地址簿三方对比、删除及冲突预览、本地密码保留、账号变更保护、只读权限、严格结果验证、二维码及有界网络恢复。
- HarmonyOS arm64/x86_64 原生库、ArkTS 和 debug HAP 已通过构建；最终产物位置为 `entry/build/default/outputs/default/entry-default-signed.hap`。
- 未安装到真机；未构建 AppGallery 正式签名 APP；未推送仓库或 Release。

## 真机验收清单

- Windows/Linux/macOS 各测一次文件会话认证（含错误密码、2FA）、新建/改名/删除、取消后收到延迟回包。
- 文件批量/文件夹上传比对内容与哈希；准备中取消、传输中取消、同名覆盖、磁盘不足和目录权限不足。
- Pro 及第三方 API 各测个人和共享地址簿：读写权限、标签、冲突、删除、失败重试、旧版接口并发修改。
- 扫描官方客户端生成配置，再让官方客户端扫描本应用配置；小屏/横屏下检查配置弹窗可滚动。
- 录像运行至少 10 分钟，导出到用户选择位置播放，检查断网、切屏、存储不足时的提示。
- Wi-Fi/移动网络切换、远端主动断开、错误凭证：只在适用情形限次恢复，不循环连接。
- Wayland 软键盘授权/拒绝与重新连接后重新授权；物理键盘组合键回归。
- 语音接通、静音、后台、息屏、通知被关闭、任务被系统撤销：确认麦克风指示与实际采集生命周期一致。
