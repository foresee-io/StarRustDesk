# 应用单层图标修正（2026-09-18）

## 本次范围

- 使用用户确认的蓝色显示器、橙色星星和连接线预览，保留原设计。
- 修正审核反馈的单层图圆角及透明像素问题：无圆角裁切、蓝色背景铺满边缘、1024×1024 RGB PNG，无 Alpha 通道或 tRNS 透明色。
- AppScope 与 entry 的 `starrustdesk_app_icon_1024.png` 和旧名称 `starrustdesk_app_icon.png` 共四份资源保持一致。
- 应用与 EntryAbility 仍引用 `$media:starrustdesk_app_icon_1024`。未启用已有模板分层图，未修改启动页素材。
- 版本保持 1.2.0（1002005）；未提交、发布或安装。本次单层修正不宣称完成全部分层图标规范或通过应用市场审核。

## 构建注意

实测当前 SDK 将被 icon 引用的 1024×1024 完全不透明源图转换为 512×512 PNG，并产生 Alpha=254 的像素。RGB/RGBA 不透明源图均复现。

`entry/hvigorfile.ts` 在默认目标资源处理后及 HAP 打包前调用 `tools/preserve-app-icon.cjs`，只恢复这张已验证单层图的原始字节。保留 SDK 原有资源校验、资源索引、其他资源及签名流程，不修改签名后包体。源图大小、RGB 编码、透明色块、两处源图一致性不满足条件时中止构建。

## 验证

- `tools/test-app-icon.cjs` 检查四份资源的尺寸、不透明性、蓝色完整边缘及配置引用，并检查打包保留逻辑的一致性和失败保护。
- Release assembleApp 通过；HAP 内两种图标名称的 SHA-256 均与源图一致。
- 图标可供应用市场单独上传：`AppScope/resources/base/media/starrustdesk_app_icon_1024.png`。
- 真机桌面、最近任务和 PC 标题栏尚需安装后目视验收。
