# 远控会话聊天与语音

开发说明：当前版本已隐藏语音呼叫入口及相关界面提示，仅展示文字聊天。以下语音部分描述保留的底层实现，不代表该功能当前对用户开放。

入口：连接远端后，在“控”功能栏选择“聊天”。手机、平板、PC 共用此入口，支持功能栏排序。

- 文字：复用 RustDesk `Misc.ChatMessage`，远端在官方聊天窗口接收，支持双向文字。不是模拟键盘输入。
- 语音：主动呼叫 → 远端接听 → 启动本地麦克风。拒绝、30 秒未接听、挂断、采集异常或连接断开时结束。
- 本地采集为 48 kHz 单声道 PCM，20 ms Opus 帧，通过当前远控连接发送。使用系统语音通信采集源。
- 静音会停止采集，取消静音才恢复；进入后台结束语音，保留原有远控后台策略。不申请后台录音权限。
- 关闭聊天面板不挂断，功能栏显示“通话中”，重新打开可挂断。
- 语音是与远端用户交谈，不是把鸿蒙麦克风注册为远端系统虚拟麦克风。
- 不新增聊天服务器、不要求 Pro 账号。能否通话取决于远端客户端的平台、版本、音频权限与是否有人接听。

## 隐私与队列

聊天正文和语音内容不写诊断日志、不落盘、不进云备份。每次连接最多保留 100 条聊天记录，每条最多 4096 UTF-8 字节，输入框最多 1000 字符。断开清空；新连接不会显示旧远端消息。

语音最多积压 10 个 20 ms 帧，队列按呼叫时间戳和远控会话隔离，挂断后的旧帧丢弃。消息与音频沿用当前连接的加密状态；若用户此前选择了未加密降级，聊天/语音也不会额外加密。

## 验证

- `tools/test-communication.cjs`：权限拒绝、等待接听、静音/恢复、后台挂断、异步权限返回过期、断线清理、输入隔离。
- Rust `communication::tests`：消息边界、时间戳匹配、会话重置、官方协议序列化。
- 需要两端真机确认：双向中文聊天、对方接受/拒绝、双向可闻音频、耳机/扬声器表现、远端系统声音恢复、网络卡顿、旋转和软键盘布局。

官方对应实现：`rustdesk/rustdesk/src/client/io_loop.rs`、`src/server/connection.rs`；协议 `hbb_common/protos/message.proto`。
