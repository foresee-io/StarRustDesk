# 折叠屏远控软键盘避让

## 本次改动

- 手机、平板不再只在横屏锁定键盘弹出前的画布高度；展开内屏、近方形内屏和折叠外屏都保持当前画面比例，不因为键盘弹出重新缩小远端桌面。
- 使用实际可见远控区域计算上移距离。以打开键盘前的鼠标位置作为输入区域参考，在边界允许时将它保留在键盘上方；上方输入位置也不会因过度上移而被裁掉。
- 避让变换作用于画布和光标共同的容器，不改用户缩放和平移参数，也不单独重建视频解码器或投屏窗口。
- 从当前页面所属窗口读取尺寸，区分键盘改变可用区域与真实的折叠、展开、旋转或窗口尺寸变化。真正变化时收起输入捕获并清除旧快照，下一次打开键盘使用新布局，远控连接保持不变。
- 诊断开启时记录画布高度、可见高度、避让偏移和是否有输入位置参考；不记录输入文字、密码、候选词或远端文本。

## 限制与验收

远控协议没有提供任意程序的输入框/文本插入点位置，本次使用最后的鼠标位置作为参考，不能保证所有远端程序中通过快捷键跳转到的输入框都能被自动定位。

`tools/test-foldable-keyboard-avoidance.cjs` 使用提取的生产方法覆盖内外屏比例、横竖屏、键盘高度变化、低/高输入位置、缩放、窗口尺寸变化和 PC 不受影响等情况。模拟尺寸不是 Mate X6 实测参数；自动检查和构建不等于折叠屏真机验收。

本轮验证：11 组折叠屏专项场景通过；包括该脚本在内的全部 48 个本地 JavaScript 回归脚本通过；Debug 签名 HAP 构建成功。版本号保持 `1.2.19（1002019）`，没有安装到设备、生成正式 APP 或发布。

真机应分别检查 Mate X6 内屏与外屏：正常比例/放大画面、上方/下方输入框、不同输入法高度、系统返回收键盘、输入期间折叠展开和旋转。确认画面比例、光标位置及点击目标一致；重新打开键盘正常，连接不被重置。
